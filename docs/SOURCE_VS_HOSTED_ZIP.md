# Source code vs. portable download

CacheNorth offers two different downloads:

| Download | Who it is for |
|---|---|
| **[CacheNorth v1.0.3.1 Full Portable ZIP](https://downloads.samsonschmidt.com/CacheNorth-v1.0.3.1-Full-Portable.zip)** | Everyone who wants to run CacheNorth; includes the launcher, AI models, offline knowledge, maps, guides and third-party notices |
| **GitHub → Code → Download ZIP** | Developers who want the source code, tests and build scripts; excludes bundled models and offline content |

**Use the Full Portable ZIP if you just want to run CacheNorth.**

The hosted file is `CacheNorth-v1.0.3.1-Full-Portable.zip` (15,993,029,771 bytes) and the maintainer-reported SHA-256 is `4D6711127EAC4803756963359AD331CA41150385B300C02D862B48B0094EAAED`. The hosted copy must be independently verified after upload.

Changing files on GitHub does **not** automatically change the portable download. The source build scripts also do not recreate the full curated library; see [Build from Source](BUILDING.md).

See [Getting Started](GETTING_STARTED.md), [release notes](RELEASE_NOTES.md), and the [release checklist](FULL_PORTABLE_RELEASE_CHECKLIST.md). The repository remains private unless the owner chooses to publish it.
