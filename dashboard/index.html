Choose the local model

Automatic mode selects a validated model conservatively for this computer. Manual choices are rechecked at every startup.

01

AI acceleration

CPU works on every computer. GPU acceleration is optional, is remembered separately for each computer, and falls back to CPU if it cannot start.

CacheNorth never installs or changes graphics drivers and never bypasses Windows security. GPU use is reported only when the AI engine confirms it.

02

Context length

How much of the conversation and documents the AI can consider at once. Larger contexts use more memory and take longer to read on a CPU. Saved for this computer only.

03

Conversation privacy

Saved conversations stay in the portable data folder until you clear them.
